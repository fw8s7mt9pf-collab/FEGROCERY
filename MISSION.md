# Mission: Learn Wayfinder And Agent Skills

## Why
Learn how to use Wayfinder and Matt Pocock-style agent skills to turn a foggy product idea into clear decisions, tickets, and build work without losing context between sessions.

## Success looks like
- You can tell when to use Wayfinder versus a normal implementation request.
- You can read a Wayfinder map and understand the current frontier.
- You can guide an agent from vague idea, to decision tickets, to implementation tickets.
- You can restart or switch sessions without losing the project thread.

## Constraints
- Keep lessons practical and tied to the grocery deal tracker.
- Prefer concise references and small exercises.
- Assume this is the first time using Wayfinder.

## Out of scope
- Learning every available skill at once.
- Building a full custom skill system.
