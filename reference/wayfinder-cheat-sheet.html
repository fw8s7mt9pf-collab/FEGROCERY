Wayfinder Cheat Sheet

Use Wayfinder when the idea is too foggy to build directly. The output is a clear route, not the finished product.

Core Artifacts

  • Map: one canonical issue describing destination, decisions, fog, and scope.
  • Decision ticket: one question that must be resolved before building.
  • Frontier: open, unblocked, unclaimed tickets.
  • Context: shared domain language in CONTEXT.md.

Ticket Types

  • grilling: ask the human until the decision is clear.
  • research: agent investigates external facts.
  • prototype: build a throwaway thing to learn.
  • task: do manual unblocker work.

End-To-End Flow

  1. Set up tracker and domain docs.
  2. Name the destination.
  3. Create the map issue.
  4. Capture known decisions, fog, and out-of-scope work.
  5. Create decision tickets at the frontier.
  6. Resolve one ticket at a time using the right skill.
  7. Record the answer on the ticket, close it, and add a one-line gist to the map.
  8. When no decision fog remains, switch to spec/build tickets.
